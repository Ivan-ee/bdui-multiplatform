# 08 - Вертикальный срез: скелет всех платформ

Type: prototype
Status: open
Blocked by: 06, 07

## Question

Собрать первый вертикальный срез всего стека, чтобы заработала главная гипотеза «один код — все клиенты»: минимальный Go-сервер с эндпоинтами каталога, отдающим данные + BDUI-layout, и клиенты, которые этот layout рисуют.

Состав:

1. Монорепозиторий: server (Go), shared (Kotlin commonMain), androidApp, iosApp, webCabinet — структура согласно подтверждённому стеку тикета «Подтверждение итогового стека». Десктоп вне скоупа (решение 27.08.2026).
2. Go: GET /objects (JSON список Объектов по модели из «Упрощённой модели данных аренды») + GET /layout/catalog (DivKit JSON), Postgres в docker-compose.
3. Android-клиент: рендер каталога через выбранный BDUI-движок на реальном API.
4. iOS-клиент: тот же экран через iOS SDK движка.
5. Веб-кабинет: страница каталога на web SDK движка (общая KMP-логика через js-таргет).
6. Зафиксировать в README шаги запуска каждой части и грабли установки среды.

Успех: один и тот же экран каталога открывается минимум на Android + Web (iOS требует mac-сборку отдельно). Результат протоколировать с артефактами и списком проблем.
