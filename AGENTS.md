# AGENTS.md

PoC сервиса аренды недвижимости: Go-бэкенд + пять клиентов на Kotlin Multiplatform,
весь UI — через BDUI (DivKit). Термины и язык проекта — в `CONTEXT.md`.

## Agent skills

### Issue tracker

GitHub Issues этого репозитория, все операции через `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Стандартный словарь из пяти ролей, строка метки совпадает с именем роли. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: один `CONTEXT.md` в корне + `docs/adr/`. See `docs/agents/domain.md`.
